# Contributing to KrishiSetu

Thanks for your interest in contributing! 🙌

## How to Contribute

1. **Fork** the repository and clone it locally.
2. Create a new branch for your change:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. Make your changes, following the existing code style.
4. Test your changes locally before committing.
5. Commit with a clear message:
   ```bash
   git commit -m "Add: short description of change"
   ```
6. Push your branch and open a **Pull Request** against `main`.

## Branch Naming

- `feature/...` — new features
- `fix/...` — bug fixes
- `docs/...` — documentation-only changes

## Code Style

- **Python (backend):** follow PEP8, use meaningful variable names.
- **JavaScript/HTML/CSS (frontend):** keep components small and readable.
- Add comments for non-obvious logic, especially in AI/ML modules.

## Reporting Issues

Use the GitHub Issues tab and include:
- What you expected to happen
- What actually happened
- Steps to reproduce (if a bug)

## Team Communication

For SIH team members — coordinate larger changes (schema changes, API contract changes) in the team group before merging to `main`.
